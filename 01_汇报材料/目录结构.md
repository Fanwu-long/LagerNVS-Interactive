# 目录结构（汇报版）

```
LagerNVS-Interactive最终版/
├── 启动本地版.py          ← 汇报主入口
├── 启动分享版.py          ← 可选公网分享
├── README.md
├── index.html             ← 打开自动进门户
├── offline_manifest.json  ← Offline 场景表（自动生成）
├── portal_config.json     ← 门户配置（自动生成）
├── DEMO_STATUS.txt        ← 当前网址状态（自动生成）
│
├── 01_汇报材料/           ← 汇报速查、讲稿要点
├── 04_说明文档/           ← 使用说明 / 对比 / 画质说明
│
├── 07_交互式渲染演示/     ← Offline 媒体 + 网页
│   ├── 01_输入视图_…      ← scene_a 等输入
│   ├── 02_输入视图_DL3DV… ← 选用场景输入
│   ├── 03_环绕轨道视频_…  ← 合格 orbit + hq_from_still
│   ├── 04_…240f/          ← 直线轨迹（选用）
│   └── 06_交互功能优化/   ← portal / free / offline / start_portal
│
├── 03_最终成果包/…        ← HQ COMPARE 静帧 + 输入缩略图（已精简）
├── 08_浏览器交互WebUI/    ← Live GPU 部署包
│
├── 99_未选用素材/         ← 软糊轨道、多余 COMPARE（不进演示）
└── 99_维护脚本/           ← 维护说明（重建 manifest 等）
```

演示只依赖根目录启动脚本 + `07_` / `03_` / 网页；`99_未选用素材` 可忽略。
