# LagerNVS Interactive 最终版（自由选择门户）

## 怎么开

```bash
python 启动本地版.py
```

浏览器：**http://127.0.0.1:8766/?v=me**

见根目录 `门户交付说明.txt`，汇报流程见 `01_汇报材料/汇报速查.md`

## 门户里自由选

| 入口 | 作用 |
|---|---|
| **自由视角** | 左侧选场景；WASD/拖拽；Live 在线可真·任意视角 |
| **Live GPU** | 实时神经渲染（本机 `:8765` 或已配置公网） |
| **Offline** | HQ→Orbit / 静帧，门户下方也可直接点场景 |
| **技术原理** | 页脚 |

## 文件夹

| 目录 | 内容 |
|---|---|
| `01_汇报材料/` | 速查、目录说明 |

| `07_交互式渲染演示/` | 门户网页 + 媒体 |
