# 使用说明（汇报版）

## 本地演示

1. 运行 `启动本地版.py`
2. 打开 http://127.0.0.1:8766/?v=me
3. 推荐顺序：自由视角 → Offline HQ→Orbit → 技术原理

## 操作

| 模式 | 操作 |
|---|---|
| 自由视角（Offline 轨） | 拖拽转向 · WASD · Q/E · 方向键 |
| 自由视角（Live） | 同上，任意位姿实时渲染（需 GPU） |
| Offline | 切场景 · HQ Still / Orbit · 拖拽 scrub |

## Live GPU（可选加分项）

1. 使用 `08_浏览器交互WebUI/02_平台启动脚本/`
2. SSH：`ssh -L 8765:<GPU_IP>:8765 …`
3. 自由视角页切换「真·自由视角」

详见 `01_汇报材料/汇报速查.md`。
