# 画质说明：雾化 / 残影 / 马赛克

## 结论

**不能把模型预测错误「修成照片级清晰」**——那是 LagerNVS 在少视角、未充分观测区域、高频纹理（草、叶、远处细节）上的固有局限。  
**能做的**：从演示包里去掉严重发糊的 Orbit、避免放大版马赛克、默认引导看 HQ 静帧。

## 原因分层

| 现象 | 主因 | 能否本机修 |
|---|---|---|
| Pred 相对 GT 发雾、边缘残影 | 神经网络新视角合成误差 | 否（需更好模型/更多视角/更高分辨率重渲） |
| Orbit 整体像马赛克、很糊 | 包内 ~640 预渲染 + 部分过软编码；`*_up` 放大加重块效应 | 部分：已剔除最差条目、不用放大版作主源 |
| HQ 静帧仍略软 | Pred 本身分辨率与模型上限 | 否；但已是包内最清晰一组 |

## 本最终版已做的缓解

1. 按清晰度筛 Orbit：去掉 demo 与多条严重雾化的 DL3DV 轨道。  
2. 保留相对清晰的：`scene_a 2v`（最佳）、`scene_a 4v`、以及 3 条合格 DL3DV。  
3. 主路径不用 `*_up.mp4`（减少放大马赛克）。  
4. 默认优先展示 **HQ 静帧（GT|Pred）**。  
5. 界面注明：雾化属模型局限，不是播放损坏。

## 若还要「真·更清晰」

需在 GPU 上重新导出更高分辨率 / 更高码率 orbit，或换更多输入视图的场景重跑推理——超出当前离线包范围。
